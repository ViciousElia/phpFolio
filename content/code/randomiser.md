## Tabletop RPG Character Randomiser

This tool, conceptualised by Wes Goodhue and originally implemented by him in an analog format, allows you to quickly generate a character concept for use in writing, tabletop rpgs, and other environments where such things make some amount of sense.

In the future, I will add more refined datasets, but for now we have a dataset based approximately on his original version.

To use the Randomiser, simply hit the button. Switching to specific tabs will Randomise only what you can see on screen.

**NOTA BENE:** The Freeze buttons currently only freeze the specific selector, NOT the selectors that are above it, so you must freeze all relevant levels if freezing a sub-item.
