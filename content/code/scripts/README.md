Files in this folder have the following properties:

- 00_ - informational only
-   _ - trash
- AA_ - files not ready for production use
- CC_ - drop-in class modules for generic classes
- MM_ - drop-in constants for consistent re-use - grouped by types
- VV_ - drop-in variable groups - often using only JSON
- ZZ_ - drop-in functional modules for ready re-use

All files without prefixes are given in camelCase.
All new js will be labelled in the following manner:

- AC_ - algorithm code (for demonstrations, primarily)
- TC_ - live tool code (for actual use on tool pages)
- OC_ - code to be bundled (for older tools not used in browser)
